# 拾词 Wordflow

面向 Android 手机的个人单词记忆应用。沿用自己的液态玻璃视觉，以“学习 / 词书 / 阅读 / 我的”四个固定入口组织背词、选书、自由阅读和个人设置。

## 安装与预览

安装包：`outputs/拾词-单元与语境记忆预览-debug.apk`（0.2.0 / versionCode 11），Android 7.0 及以上，开发签名测试版。此文件已于 2026-10-01 发布到[线上下载入口](https://wordflow.43.134.190.112.sslip.io/releases/wordflow.apk)，可通过应用内“检查更新”获取。

当前本地安装包为 `outputs/拾词-首次设置-0.3.2-debug.apk`（versionCode 23）：已于 2026-10-02 发布到线上下载入口。新增首次启动的欢迎与设置流程（不需要注册账号）：欢迎页后依次选择昵称和头像、目标词书、每天词量、选读难度，确认后才进入应用，也可以在欢迎页直接从备份恢复。已有词书或单词的老用户升级后不会看到这一流程。上一版 0.3.1（versionCode 22）把阅读页改为入口加逐级选择（难度、主题、列表），难度覆盖 A2 到 C2，已于 2026-10-02 发布到线上下载入口；前一版 0.3.0（versionCode 21）新增了在线选读库（见“英语选读”）。前一版 0.2.9 已于同日发布到线上下载入口（0.2.8 未单独发布，已包含在内）。0.2.9 在 0.2.8 基础上对词库释义做了第二次查阅，共校正 1198 条释义（`src/gloss-fixes.ts`，按原始释义全文匹配，用户自己改过的释义不受影响）。0.2.8 的变化：学习卡片不再显示音标（音标只在长按后的详情页显示，已删除“隐藏音标”开关）；详情页分为“释义 / 助记 / 词典”三个标签页；“检查更新”改为三步（先读取当前版本，再查询最新版本，确认后才下载安装）；英语选读扩充到 22 篇并新增“全部选读”列表、主题筛选、词书单词提示和“加入我的词本”；核心释义的提取规则修复了缺词性、括号内逗号和词形说明等问题。已通过 57 项逻辑检查和 24 项网页回归。

APK 自带界面、词书及首批英语选读，无需电脑服务。学习、标记、复习、选读和备份可离线使用；更新文章、在线词典和 AI 生成需要联网。采用 Capacitor Android 容器与 React 界面，不是 Kotlin/Compose 全原生 UI；SQLite、密钥加密、AI 请求、文件导出和系统朗读由原生代码处理。

开发预览仅监听回环地址，默认 `http://localhost:4173`，可通过 `PORT` 更改。新版客户端要求 API v7，拒绝连接旧接口；学习数据使用 v3 格式，兼容读取 v1/v2 备份，升级后拒绝旧格式覆盖新记录。

## 界面与学习

- 玻璃液态风格为现有视觉基线。按钮、分段切换、底栏、输入框和抽屉复用 `src/theme.css` 的玻璃材质变量；深色通过 `src/appearance.css` 调整同一套材质，并同步安卓系统栏。
- 学习页先选择“新词 / 到期复习”，再显示词书单元、当前组与完成进度。操作统一为“看词 / 读短文 / 自测”：看词同时显示英文和释义；自测隐藏释义，可在提交前展开核对、标记或取消不熟。模式在翻页、重启和备份后保留。
- 每词固定显示六个小圆点。自测点按记录“本轮不熟”，同一轮仅增加一次标记，左滑可取消；速览和详情中的六点为独立难词标记，不决定本轮成绩。长按可查词、发音或标熟。
- 最高六级，历史大于六次的原始计数不因升级清空。达到六级后仍能记录本轮不熟；增加标记不会抹掉“已学”的事实。
- 底部固定为学习、词书、阅读、我的四个入口。页面复用标题、用途说明、主要操作与返回规则，保留玻璃选中滑块和磨砂抽屉。词书、阅读为主页面，单词库和设置详情为子页面；从语境记忆打开 AI 设置后，返回原学习组。
- 学习页只保留“新词 / 到期复习”两个任务入口。新词按当前词书的“第 N 单元”选取；复习显示“全部词书”，按实际到期时间去重；“回看本单元”用于提前练习。每组最多 20 词，任务最多选取 100 词。原分组和词序保留。
- 每个词书单元分别保存未完成的新词任务，包括固定词表、分组位置和本轮不熟词；切回来或重启后继续原位置。到期复习保存一份独立任务，中途新增到期词留待后续任务。标熟或删除的词保留占位，提交时跳过。
- 同一任务可“看词”或“读短文”。语境短文只使用当前组的词，阅读和查词不记成绩；点击“进入本组遮义自测”回到同一组，再按已有提交规则记录结果。
- 默认使用艾宾浩斯式固定间隔：20 分钟、1 天、2 天、4 天、7 天、15 天、30 天，间隔从上次完成计算，末级每 30 天巩固。忘记后 5 分钟重学，再从 20 分钟开始。这是应用预设，不声称是个人测得的遗忘曲线。
- 设置中保留 FSRS 自适应计划；切换不重写历史或现有到期日期，下次完成时生效。顶部复习计划用表格列出各阶段间隔、忘记后的重学规则，并显示到期数量、未来 7 天已排数量和下次复习。
- “本组已检查完”确认剩余词已自测记住，一次保存结果、到期时间及提交凭据；完成后主动进入下一组。重复提交不重复计数，整组撤销在重启后仍可用；自由练习不更新复习计划。
- 今日新学按明确首次学习时间计数，今日复习按正式复习去重；历史记录可证明已学，但迁移时不补造首次日期。
- 新词标签显示本单元待学数量，到期复习标签显示全词库当前到期数量；本次任务单独显示已完成组数。中途新增到期词单独提示，继续原任务时跳到未提交组并保留答案，本次结束后再处理其他到期词。
- 复习计划优先显示可继续的任务和操作入口，再展示间隔规则；暂无到期任务时说明下次复习时间，并可转到学习新词。
- 保留减少动画、减少透明度和增强对比度偏好。液态玻璃是 Android WebView 内的视觉实现，不是苹果原生材质。

## 词书

词书为固定主导航，也可从学习页顶部或“我的”进入。一次突出一本正在学习的词书，其他词书保留各自进度。管理页包含“我的词书”和“添加词书”，提供当前词书的继续学习、全部单词查找、考频查询与导入入口。内置高考、四级、六级、考研、雅思、托福六类 ECDICT 标签词表，共 11,427 个去重词条；考研按英语一、英语二拆成独立计划，因此选书页有七项。它们不是官方考试大纲或商业出版词书，具体数量和来源在界面中标明。

- 加入词书时设置每单元 5 至 100 词，支持任意整数。新计划按单元上限分配，最后单元不并入前一单元；旧计划仍保留原有分组。“单元”是词书计划序号，不是日历日期；可以一天学多个单元，也可以分几天完成一个单元。
- 同一本书的单元计划固定，熟词和复习不会改变原始词序。设置中的单元词量默认值仅影响新加入的词书。
- 新加入的四级、六级、考研英语一/二词书，先按各自近五年考频排序，再划分 Day。旧词书不自动重排，高考/雅思/托福仍用原词序。学习页核心释义的批量整理尚未完成，当前仍保留原中文释义。
- 多本书共用同一英文词条、标记和复习记录；加入新书不会覆盖已有中文释义。缺失音标和英英释义可由内置词库补充。
- 原有词库在读取时兼容迁入“我的词本”，保留词条 ID、标记和复习记录。CSV、TSV、TXT 导入也进入我的词本。
- 词库的搜索入口仍提供全部单词、已标记、熟词、释义编辑和删除。删除词条会从所有词书移除，并清理相关记录。

数据位于 `public/vocabulary/`。`source.json` 记录源提交及校验值，随包附带 `ECDICT-LICENSE.txt`。可复现构建命令：

```sh
node scripts/build-wordbooks.mjs
```

## 近五年考频

词库内的“考频”页提供 2022–2026 年卷面考频，四级、六级、考研英语一/英语二分开。按出现试卷数、总词次排序；所有原词条保留，零命中词列在后面。这个独立查询页不会改动已有词书顺序、Day 分组或学习记录。

- 来源为懒笔记第三方真题页面，非官方统计。当前快照包括四级/六级各 33 套（11 考期，至 2026 年 6 月），英语一/二各 5 套。
- 只计算卷面英文正文、题干与选项；不包含听力录音原文、写作指令、中文题目、答案、解析或参考范文。共用听力/阅读模块在每套实际试卷中分别计数，同卷重复副本去重；另保留考期覆盖数。
- 匹配当前 ECDICT 分类词书，采用小写及无歧义屈折变形归并，保留真实独立词头；不做上下文词义消歧。零命中不是“历年从未考过”，更不是“没有学习价值”。
- 原始页面仅在 `.local/exam-frequency/` 校验缓存中，不随 APK 分发。应用和 `outputs/exam-frequency-*.csv` 仅带独立计算的计数与来源；第三方原始材料的再利用授权未确认。
- `outputs/exam-frequency-2022-2026.json` 保留卷目、原页 SHA-256、模块及统计口径，便于核验。首次联网采集，之后可加 `--offline` 从缓存复现。

```powershell
python -m pip install -r scripts/requirements-exam-frequency.txt
npm run build:exam-frequency
npm run test:exam-frequency
```

## 词典与发音

本地中文释义和可用英英释义来自词表/ECDICT。长按详情中的在线词典接入 Free Dictionary API，仅发送当前单词，展示返回的英英释义、例句、可用录音、来源与许可；查询失败时保留本地内容。欧路入口仍是外部客户端/网页跳转，不冒充欧路 API。

英美系统朗读和语速在设置中选择。单词缺少系统语音时尝试在线词典录音，录音口音以来源实际提供为准；短文朗读需要系统英语语音。在线服务与设备语音可用性受网络及设备环境影响，不能把模拟接口回归当作真实录音或听感验收。

## 语境记忆、词汇短文与 AI

“学习 -> 读短文”即语境记忆，按当前任务和词组保存短文，每篇最多 20 个词；新词和到期复习均可使用。旧短文的目标词与当前组完全一致时可直接复用。

“阅读 -> 自选词短文”保留为独立自由阅读入口，可选择词书单元和目标词，每篇最多 40 个词。浏览这里的单元不会改变学习任务的单元位置；页面提供返回当前学习组语境记忆的入口。

- 生成连贯英文短文和对应译文；目标词可点击查义，译文默认折叠，提供朗读与停止。
- 覆盖率从实际英文正文计算，未出现的词明确列出，不相信模型自报的覆盖率。
- 短文按词书、Day、分篇保存，重开不重复请求。生成期间保留新标记；词表或释义改变时拒绝保存过期结果。
- 短文不会自动调用模型；先在页面选择要记忆的单词，再按当前选择生成，已生成内容按词书、Day、分篇保存，失败保留手动重试入口。
- 修改释义会清除相关旧助记，修改音标、例句不清除。单词联想保留在详情里作为辅助。
- 语境记忆末尾进入同组遮义自测；自由阅读中的词汇短文不跳转到另一批词。进入阅读或自测不伪造复习完成，仍需手动提交学习组才更新计划。

AI 服务商、模型和密钥统一放在“我的 -> AI 服务”。内置 DeepSeek、OpenAI、通义千问的模型选项，并允许填写自定义模型名称；没有内置私人密钥、免费调用额度或本地大模型权重。默认模型名不代表当前账户已验证连通。

手机通过原生网络直连所选服务商，电脑预览使用本机服务。只发送目标词 ID、英文和释义，不发送整本词库、标记或复习记录。60 秒超时，失败不覆盖旧内容，费用由服务商按账户收取。

## 英语选读

- 阅读页只放入口，不堆长列表：今日英语选读、自选词短文、“适合你”推荐（3 篇）和“按难度选读”。难度分 A2 入门、B1 初级、B2 中级、C1 高级、C2 精通；点进一个难度，文章多时先按主题选，再进入每次显示 15 篇的列表，文章少时直接进列表。阅读器的上一篇/下一篇只在所选难度（和主题）内切换。自带 22 篇来自 Wikipedia / Simple English Wikipedia，保留原文段落而非 AI 改写，并配中文译文；自带文章没有 AI 评级，基础归入 B1、进阶归入 B2。文中出现在词书里的单词会列出，查词面板可一键加入我的词本。
- 基础/进阶是选读参考，不是 CEFR 测评结果。默认参考当前目标词书，也可在“我的 -> 发音与阅读”手动选择难度及正文字号。
- 原文、署名、摘录时间及文字许可随文章保留；图片单独核对来源与许可。内容和对应图片随 APK 离线提供，详情见 `public/reading/README.md`。
- 点词优先查个人词库或本地 ECDICT，未收录时可手动查询在线词典；提供朗读、原文入口和已读记录。完成阅读不改词书进度或复习日期。
- 文章内容默认从本地摘录读取，更新原文需要用户主动点击更新；失败保留本地内容，成功结果缓存于当前设备。文章下方可随时调用 AI 做摘要、重点词提取或全文翻译；不会向文章来源发送个人资料或学习记录。

### 在线选读库（0.3.0）

除 APK 自带的 22 篇外，云端服务器维护一个会增长的选读库（`cloud/library_pipeline.py`、`cloud/library_store.py`，数据在 `/srv/wordflow/library/`）。

- 来源：Wikipedia 的 Vital Articles 条目，同时取 Simple English 与 English 版本。英文段落原样摘录，不由 AI 改写；每篇记录条目、版本号、作者页、CC BY-SA 4.0 许可，图片来自 Commons 并记录作者与许可。
- 程序负责筛选：按词表词频统计生僻词比例、划分 CEFR，规则拒绝过短（70 词以下）、罕见词过多（30% 以上）、列表式和争议类条目。难度覆盖 A2 到 C2：除 Vital Articles 外，另有一批日常主题（动物、食物、家庭、交通等）只收 Simple English 版作为入门材料；被长度或生僻词规则拒绝的标题，可用 `run --retry` 重新判定。DeepSeek 负责复核：质量判定、CEFR、主题标签、一句话导读、逐段中文译文。AI 判为拒绝或输出格式不合法的文章不入库；译文段数必须与原文一致。
- 服务：`/v1/library?since=&limit=` 按序号增量提供，`/v1/library/image/<id>` 提供图片。`wordflow-library.timer` 每天 03:40 运行一批（默认 20 个标题，库上限 400 篇），密钥放在服务器 `/etc/wordflow/library.env`（`LIBRARY_AI_KEY=`，仅 root 可读），没有密钥时不运行 AI 步骤。手动隐藏的文章不会被再次收录：`python3 cloud/library_pipeline.py hide <id>`。
- 手机：阅读页进入时在后台增量同步，缓存在本机，离线可读；服务下架的文章会从缓存删除。阅读页新增“适合你”推荐（按你的词书和已学单词估算生词比例，目标约 4%）、按难度和主题逐级选择、同步状态和“更新选读库”按钮。同步失败时继续使用本机缓存及自带文章。
- 词表由 `npm run export:library-wordlist` 生成（`cloud/library-wordlist.txt`）。检查：`python tests/library_test.py`（不要用 `-m unittest tests.library_test`）。

```powershell
npm run build:reading
```

构建器缓存来源响应、控制请求频率并遵守限流等待。维护数据后重新构建 APK；日常使用不需要运行构建器。

## 我的与设置

“我的”先显示头像、昵称、学习目标和真实学习统计，再按“学习与显示 / 服务与数据”组织学习设置、外观、发音与阅读、AI 服务、我的单词、数据与备份。子页说明设置的作用；备份区分本机文件和手动云端备份，恢复码入口按需展开。

外观可选浅色/深色、系统/衬线/黑体/等宽字体、常规/中等/粗体字重和标准/大号字号，随学习记录及备份保存。

个人资料在本机保存，不提供注册。头像从本地图片选择，在设备内裁成方形并压缩为 256 像素后保存，不上传到第三方。学习天数按复习记录统计，已读文章按手动完成的去重文章计数。

## 保存与备份

- Android 数据保存在应用私有 SQLite `wordflow.db`；退出和重启保留，卸载清除。大记录分段读取，避免 Android CursorWindow 单行限制。
- 导出使用系统“另存为”，无需全部文件访问权限；大备份暂存应用缓存后流式导出，不放进 Activity 状态包。
- JSON 备份包含词书、学习草稿、提交/撤销记录、短文、个人资料、偏好和已读记录，不包含 AI 密钥及文章缓存；兼容旧备份。恢复需确认并覆盖当前学习数据，异常草稿单独跳过并提示。
- 保存失败时保留待保存副本，暂停新的修改，提供重试、导出副本和明确放弃入口。响应丢失先核对设备记录，发生版本冲突时不覆盖较新状态。未写入的结果不能保证在强制关闭后恢复。
- Android API Key 使用系统 Keystore 的 AES-GCM 密钥加密，读取配置不返回密钥；禁用自动系统备份和桥接日志。电脑预览服务的密钥仍保存在 `.local/wordflow.sqlite`，不要分享 `.local` 或 `.env`。
- 不提供自动跨设备同步；更换手机或卸载前先导出备份。单份学习记录及备份上限 12 MiB，超过上限拒绝保存，不清空旧记录。
