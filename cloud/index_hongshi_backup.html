01The Mechanism // 认知机制

See it. Hide it.
Try to recall.

看懂释义，并不等于真正掌握。

大多数背词应用让人沉迷于“眼熟”的虚假安全感。拾词在双列卡片中默认遮挡中文释义，将自测变成一次微小的大脑检索阻力——唯有迫使神经回路经历主动提取，记忆印痕才真正形成。

02The Scale // 阻力分级

Six quiet dots.
Never binary.

记忆从来不是非黑即白的开关。

每张卡片下方固定排布六颗微小的标记点。难词点按逐级升级，熟词随时标熟移出主队列；达到六级并不等于永久掌握。在未来的检查中再次生疏，仍会如实降级并解除完成状态，真实映射记忆衰减。

03The Rhythm // 记忆曲线

Spaced in time,
until it hardens.

只有真正完成整组，才更新复习计划。

预设 20 分钟、1 天、2 天、4 天、7 天、15 天、30 天的经典固定时间间隔；忘记后 5 分钟重学，重新开始。同时支持自由切换至新一代 FSRS 自适应算法。表格化列出各阶段到期任务，不伪造复习，不堆积负担。

  • 20m Initial consolidation 短期记忆突触沉淀
  • 1-7d Spaced intervals 抗遗忘周期阶梯
  • 30d Long-term mastery 稳固长时记忆回路
04The Context // 语境短文

Isolated words die.
Sentences breathe.

词汇只有活在句子中，才具备语感生命。

“阅读 ➔ 今日短文”依据当日计划中的目标生词，端侧一键编织为连贯自然的英文小短文与对应译文，严格从实际英文正文统计词汇覆盖率；同时附带 14 篇精选 Wikipedia 原文分级阅读，点词即查，系统级纯正发音。
