# 拾词 AI 说明

AI 在拾词里只是“需要时才问的帮手”，不在学习主流程里。背词、复习、标记、选读都不依赖 AI，断网也能用。

## 入口

| 位置 | 作用 | 用的是哪种 AI |
| --- | --- | --- |
| 页面右上角的星星按钮（学习页在“复习计划”旁） | 打开 AI 助手，像聊天一样提问 | 内置 AI |
| 单词详情右上角的星星按钮；“助记”页没有助记时的“问 AI 怎么记” | 针对这个单词提问 | 内置 AI |
| 阅读时点单词 → “翻译本句”“语境释义” | 一句话的译文、单词在这句里的意思 | 内置 AI |
| 学习 → “短文”标签 → “生成本组短文” | 用这一组单词写一篇短文（这是唯一的短文入口） | 内置 AI，或你自己的 API Key |

已经去掉的功能：阅读页的“AI 助读”面板和逐段“AI 解析”、全文 AI 翻译、阅读页“语境记忆”入口和自选词短文、单词详情里的“AI 生成联想”按钮。全部 11,427 个考试词已自带助记，没有助记的词就不显示，也可以自己写。

## AI 助手

- 上下文：助手会自动带上你当前看的内容。文章页带文章标题和全文；单词详情带这个词、释义和例句；学习页带当前这一组单词；其他页面是通用问答。对话框顶部的标签可以点“×”去掉上下文，改为不带上下文提问。
- 历史：每篇文章、每个单词、每组单词各有一份对话，通用问答共用一份。历史只保存在本机（`localStorage`，最多 30 份、每份 40 条），可以随时“清空记录”。
- 范围：只协助英语学习（词义、用法、语法、翻译、阅读理解、记忆方法）。资料里的文字只当学习素材，不当指令。

## 额度

内置 AI 由 Wordflow 云端服务代理，使用服务器上的密钥，不在 APK 里。

- 每台设备每天 60 点，北京时间 0 点刷新。问一次 1 点，生成一篇短文 5 点。
- 设备用一个匿名随机 ID 计数（`wordflow.ai.device`，不含个人信息）。同一个 IP 另有 5 倍的总上限，用来挡住反复重装刷额度。
- 请求失败会退回点数。超额时服务器返回 429，应用显示“今天的 AI 次数用完了，明天再来”。
- 句子翻译、语境释义的结果在服务器缓存，命中缓存不扣点。
- 服务器用环境变量 `AI_DAILY_LIMIT` 调整每日点数。

## 自己的 API Key

“我的 → AI 服务”可以填写 DeepSeek、OpenAI 或通义千问的密钥。它只用于生成语境短文：填了之后短文不占内置额度，费用由服务商收取。密钥保存在手机上（原生加密存储），不进备份。AI 助手和查词始终使用内置 AI。

## 发送了什么

- 助手：你输入的问题、最近 12 条对话，以及上面说的当前内容（文章全文最多 12,000 字符）。
- 翻译本句 / 语境释义：那一句话和被点的单词。
- 短文：这一组的单词和释义。
- 不发送：整本词库、标记、复习记录、昵称和头像。服务器不保存对话内容，只记录额度计数。

## 接口

`POST /v1/ai/chat`（只接受应用自身的来源）

```json
{
  "device": "匿名设备 ID",
  "messages": [{ "role": "user", "content": "…" }],
  "context": { "kind": "article", "title": "…", "text": "…" }
}
```

`context` 可以是 `{kind:'article', title, text}`、`{kind:'word', word, meaning, sentence}` 或 `{kind:'study', words:[{word, meaning}]}`。一次性任务用 `task` 代替 `messages`：`{type:'sentence', sentence}` 或 `{type:'word', word, sentence}`。返回 `{reply, model, remaining}`。

`POST /v1/ai/reading` 的短文模式（`mode: 'story'`）同样计 5 点并返回 `remaining`。旧模式（导读、全文翻译等）只为没升级的老版本保留。

客户端统一在 `src/ai.ts`，服务端在 `cloud/wordflow_cloud.py`，测试在 `tests/reading_ai_test.py`。
